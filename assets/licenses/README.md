- SYNTAXES.md is generated by `gitk-rs --licenses` from two-face
  0.5.2+bat-0.26.1's embedded syntax/theme acknowledgements.
- two-face-LICENSE-* preserve that bundle provider's MIT/Apache notices.
- gpui-component-assets 0.5.1 embeds the UI icons and declares Apache-2.0;
