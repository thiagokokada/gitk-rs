# Bundled syntax coverage

213 bundled syntaxes. Generated by `gitk-rs --list-languages` from two-face
0.5.2+bat-0.26.1 (syntect, pure Rust fancy-regex backend).

Detection uses filenames, extensions, then shebang/first-line rules.
Unknown languages retain normal diff colors. Parsing runs off the UI thread.
Multiline state is tracked separately for old/new code and reset at hunk gaps;
missing context may prevent perfect coloring inside a partial multiline construct.

Grammars and themes are embedded offline. See [license acknowledgements](../assets/licenses/SYNTAXES.md).
